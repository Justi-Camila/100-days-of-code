### 1. Exercícios Carro (Java Básico)

Objetivo: Criar a classe Carro com menu no Main, em que cada ação valida o estado (não dá para parar um carro já parado) (pasta `java-basico/carro`)

Principais aprendizados:

- Duas variáveis com a mesma informação divergem (`parado` e `velocidade`) 
- Caminho de erro não deve alterar o estado

### 2. Exercícios TV (Java Básico)

Objetivo: Criar uma classe TV com menu no Main, em que cada ação valida o estado (não dá pra desligar uma tv que já está desligada) (pasta `java-basico/tv`)

Principais aprendizados:

- Cada método de ação precisa checar se a TV está ligada antes de agir
