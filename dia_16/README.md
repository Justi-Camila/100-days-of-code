### 2. Java Singleton Pattern

Objetivo: Implementar a classe Singleton (construtor privado, campo estático e getSingleInstance) e usá-la para imprimir a frase com o texto da entrada

Principais aprendizados:

- A String str é pública neste exercício, porém em uma aplicação seria privada, sendo acessada pelos métodos getters e setters
- O padrão Singleton garante apenas uma instância, essa forma não é segura utilizando várias threads
- Complexidade: O(1) de tempo e de espaço
- Principal dificuldade: o enunciado dizia que não havia input, mas o exemplo e o editor exigiam ler “hello world”; quando o texto e o exemplo discordam, o exemplo (os testes) prevalece
- Total de dicas: 4 dicas (entender o formato do exercício)
- Próximos passos: iniciar o Singleton thread-safe
